# Sample Data for Testing

This directory contains sample documents for testing the ingestion engine.

## Files

- `sample_calibration_cert.txt` - Sample text representing a calibration certificate
- `sample_test_report.txt` - Sample text from a PV test report
- `test_document.txt` - Simple test document for basic parsing tests

## Note

For full testing with actual PDF and Word files, you would need to:

1. Create actual PDF calibration certificates
2. Create Word test reports
3. Create scanned PDF samples for OCR testing

These text files simulate the extracted content for development and unit testing purposes.
